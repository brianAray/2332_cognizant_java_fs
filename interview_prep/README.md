# Skills Requirement

## Java SQL NoSQL REST

### Required
- Hands-on-knowledge of basic OOP patterns (Observer, Factory, Singleton, DAO, etc.)
    - Also how to apply these to Java and Spring
- Working knowledge on CRUD operations with RDBMS with focus on SQL Fundamentals.
- Focus on unit testing using JUnit and Mockito with emphasis on TDD

### Preferred
- Overview of MongoDB with an understanding of the architecture
- Understanding of threads in context to thread safe programming

### Stretch
- Can construct efficient SQL queries employing JOINs, subqueries and aggregate functions

## Spring & Hibernate

### Required
- Working knowledge of Spring modules (Core, Web, Data, Cloud, etc.) and on Spring Boot.
- Hands on exposure to Hibernate ORM with an emphasis on architecture

### Preferred
- Ability to implement Spring Data JPA, Spring Boot Actuator, and provide test coverage

### Stretch
- Overview of API documentation using tools like Swagger.

## Web Dev with React / Angular

### Required
- Working knowledge of the React / Angular framework with focus on API integration.
- Good knowledge of JavaScript / Typescript with focus on developing wireframes.

### Preferred
- Ability to develop micro-frontends (MFEs) for the UI Components

### Stretch
- High level overview of asynchronous programming through JavaScript

## DevOps (CI/CD), Event Driven Architecture & Microservices

### Required
- Understanding of building tools (Maven)
- Hands on usage of code versioning tools like Git
- Understanding of CI/CD pipelines using tools like Jenkins
- Grasp of containers, Docker, and leveraging cloud platforms like AWS
- Hands on implementation of Microservices architecture with focus on API Gateway, service discovery, and load balancing

### Preferred
- Basic security coverage through Spring with focus on authentication and authorization
- Hands on understanding of Event driven architecture and paradigm using Kafka
- Familiarity with branching strategies and collaboration within Git workflows.

### Stretch
- High level overview of Kubernetes for orchestration
